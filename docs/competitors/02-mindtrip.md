# Mindtrip Screens Audit

| Screen            | Purpose                          | Main Use Case                          | Key Features                                              | Why It Matters                        |
| ----------------- | -------------------------------- | -------------------------------------- | --------------------------------------------------------- | ------------------------------------- |
| Chat Home         | AI travel assistant landing page | Start trip planning conversation       | AI prompt box, recommendations, jump back in, create trip | Entry point into ecosystem            |
| Trips             | Persistent trip dashboard        | Manage all trips                       | Trip cards, filters, receipts, saved trips                | Converts chat into long-term planning |
| Explore           | Discovery + maps                 | Browse restaurants, stays, attractions | Search, filters, map pins, categories                     | AI + Google Maps hybrid               |
| Trip Workspace    | Central trip operating system    | Organize itinerary                     | itinerary, ideas, bookings, chats, calendar, media        | Core product layer                    |
| Itinerary         | Timeline planning                | Build day-by-day trip                  | daily schedule, add items, trip flow                      | Operational planning                  |
| Calendar          | Time management                  | Schedule activities                    | drag/drop events, calendar view                           | Makes AI actionable                   |
| Ideas             | Saved candidate places           | Collect options before booking         | saved entities, add/remove                                | Decision workspace                    |
| Bookings          | Reservation management           | Store confirmed bookings               | hotel/flight/activity tracking                            | Trip logistics                        |
| Chats             | Trip-specific memory             | Revisit conversations                  | saved AI chats per trip                                   | Persistent AI memory                  |
| Media             | File/link storage                | Organize travel docs                   | links, screenshots, PDFs                                  | Centralized travel assets             |
| Saved Collections | Pinterest-style saving           | Save themed places                     | collections, folders, categories                          | Retention engine                      |
| Saved Places      | Personal map memory              | Save restaurants/hotels                | cards, ratings, categories                                | User personalization                  |
| Inspiration       | Social discovery feed            | Discover guides/trips                  | creator guides, likes, saves                              | Growth + engagement                   |
| Creator Hub       | Creator monetization             | Publish travel guides                  | earnings, commissions, links                              | Marketplace layer                     |
| Updates           | Notifications/feed               | Re-engagement                          | announcements, reminders                                  | Retention                             |
| Profile           | User identity                    | Manage traveler profile                | social links, bio, preferences                            | Personalization                       |
