

# Executive Summary

Use **OpenClaw now**, but only as the **execution layer**.

```text
Paperclip = manager / approvals / budgets
Hermes = brain / research / lead scoring
OpenClaw = hands / WhatsApp / browser / scraping / actions
Postiz = social publishing
Supabase = CRM + source of truth
OpenAI = model provider
```

OpenClaw is a self-hosted gateway that connects chat apps and channels like WhatsApp, Telegram, Slack, Discord, etc. to AI agents. ([GitHub](https://github.com/openclaw/openclaw/blob/main/docs/index.md?utm_source=chatgpt.com "openclaw/docs/index.md at main")) Its gateway exposes a typed WebSocket API, validates frames, and emits events like health, heartbeat, cron, chat, and agent events. ([OpenClaw](https://docs.openclaw.ai/concepts/architecture?utm_source=chatgpt.com "Gateway architecture"))

## 1. Daily Contact Discovery

```text
Paperclip daily task
→ OpenClaw runs Apify/Firecrawl
→ Hermes scores contacts
→ Supabase saves contacts
→ Paperclip approval required
→ OpenClaw sends only approved outreach
```

## 2. WhatsApp Concierge

```text
Lead messages WhatsApp
→ OpenClaw receives
→ Hermes classifies intent
→ Supabase updates CRM
→ OpenClaw replies
→ Paperclip audits
```

## 3. Instagram Signal Collection

```text
OpenClaw collects public signals
→ Hermes scores intent
→ Supabase stores profile
→ no auto-DM unless approved
```

## 4. Event Promotion

```text
Supabase event
→ Hermes creates campaign
→ OpenClaw gathers audience
→ Postiz schedules posts
→ Supabase tracks clicks/sales
```

## 5. Rental Lead Follow-up

```text
New rental lead
→ Hermes qualifies
→ OpenClaw sends WhatsApp follow-up
→ Supabase logs thread
→ Paperclip flags stale leads
```

