## 1. Executive summary

mdeapp is one F02-F03 commit away from being a clean CopilotKit + Mastra shell. The Phase 1 automation strategy should be **minimal, hook-driven, and verification-first** — the legacy app's draft hooks already encode every rule CLAUDE.md cares about. Your fastest production-readiness lift is **promote 8 of 12 draft hooks** (skip 4 that target Maps/Supabase code not yet present) + add **5 MCPs** (Supabase, Playwright, Chrome DevTools, Vercel, Context7) + **3 subagents** (security, copilotkit-reviewer, supabase-reviewer) + **5 slash commands** (/verify-floor, /supabase-rls-audit, /copilotkit-check, /maps-audit, /release-checklist). Defer everything else until W5 when real surfaces exist.

**Headline risks to avoid:** (1) promoting Maps/Stripe hooks before any maps/stripe code exists → noisy false positives; (2) installing official `code-review`/`feature-dev`/`supabase` plugins → duplicates existing skills; (3) running CopilotKit MCP — endpoint is down, will block sessions.

## 10. Automation architecture

```
┌──────────────────────────────────────────────────────────────────────┐
│                       Developer keystroke                            │
└─────────────────┬────────────────────────────────────────────────────┘
                  │
        ┌─────────▼─────────┐
        │ PreToolUse hooks  │  ← guard-sensitive-paths, scan-secrets,
        │   (blocking)      │     no-service-role-in-src, dist-leak-scan
        └─────────┬─────────┘
                  │
            ┌─────▼─────┐
            │  Tool ran │
            └─────┬─────┘
                  │
        ┌─────────▼─────────┐
        │ PostToolUse hooks │  ← lint-edited-ts, typecheck-edited-ts
        │   (warning)       │     (only edited files)
        └─────────┬─────────┘
                  │
                  ▼
        (continues editing… end of turn)
                  │
        ┌─────────▼─────────┐
        │   Stop hooks      │  ← stop-rls-gate
        │   (warning)       │
        └─────────┬─────────┘
                  │
   ┌──────────────┴──────────────┐
   ▼                             ▼
[Author runs                [Pre-PR:
 /verify-floor]              /release-checklist
                              invokes 3 subagents +
                              Playwright MCP]
```

|Layer|Owner|Latency|Failure mode|
|---|---|---|---|
|PreToolUse (blocking)|Claude session|50-200ms|Edit refused; user re-prompts|
|PostToolUse (warning)|Claude session|1-3s|Warning surfaced; agent decides|
|Stop (warning)|Claude session|2-10s (Supabase MCP call)|End-of-turn warning|
|Slash commands|Author|10s-5min|Reported in chat|
|Subagents|Author via `/security-check` etc.|15-60s|Reported in chat|
|Vercel CI|GitHub Actions|60-180s|PR blocked|

### Safe auto-fix boundaries

|Auto-fix|Safe|
|---|---|
